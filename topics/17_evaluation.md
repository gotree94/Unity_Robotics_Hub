# 3. 평가 기준

## 3.1 성적 배분

| 항목 | 비율 | 세부 기준 |
|---|---|---|
| 출석 | 10% | 결석 1회당 -2%, 지각 3회 = 결석 1회 |
| 과제 | 20% | 주 1회, 총 13회 과제 (최하위 3회 제외) |
| 중간 프로젝트 | 30% | 8주차 발표 및 제출 |
| 기말 프로젝트 | 40% | 15주차 발표 및 제출 |

## 3.2 과제 감점 기준

| 항목 | 감점 |
|---|---|
| 지연 제출 (1일당) | -10% (최대 -50%) |
| 미작동 코드 | -30% |
| 주석 미포함 | -10% |
| ROS 연결 실패 | -20% |
| 표절 | 0점 처리 |
